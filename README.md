Java Syntax Colours in IntelliJ IDEA – What They Mean
Colour	    What It Represents	                Example
Purple	    Field (Instance Variable)	        private String name;
Blue	    Java Keyword	public, class,      if, return
Yellow	    Static Field or Static Method	    System.out, Math.PI
Green	    Local Variable or Method Parameter	int count = 0;
Orange	    Class Name or Interface Type	    String, List, MyClass
White/Grey	Method Name or Literal	            toString(), "hello", 123

Notes
- Hover over a coloured word to see its declaration.
- Ctrl+Click (Cmd+Click on Mac) to jump to its definition.
